# 🛍️ Shop API — E-Commerce Backend Showcase

Production-ready e-commerce backend built with NestJS, designed for scalability and high performance.

> **Note:** This is a public showcase repository containing documentation and architecture overview. The source code is proprietary.

## 🚀 Key Features
- **Guest Checkout:** Seamless cart & order creation for unauthenticated users.
- **Payments:** Integrated **WayForPay** payment gateway.
- **Shipping:** Automated **Nova Poshta (TTN)** integration for delivery tracking.
- **Performance:** Caching and session management with **Redis**.
- **Architecture:** Modular structure with **31 DTOs** and strict validation.

## 🛠️ Tech Stack
- **Framework:** NestJS 11
- **ORM / DB:** TypeORM, PostgreSQL
- **Cache:** Redis
- **DevOps:** Docker, Google Cloud Run
